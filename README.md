# Smart Blind Stick with Telegram Emergency Alert System

## Overview
A smart assistive walking stick designed for visually impaired individuals. The system uses an ultrasonic sensor to detect nearby obstacles and provides real-time alerts through a buzzer and servo motor. It also includes an emergency SOS button that sends instant Telegram notifications to caregivers or family members via WiFi.

## Technologies Used
- ESP32
- Arduino IDE
- C++
- WiFi Communication
- Telegram Bot API
- HC-SR04 Ultrasonic Sensor
- Servo Motor
- Buzzer

## Features
- Obstacle detection using ultrasonic sensors
- Real-time audio alert through buzzer
- Servo motor activation when obstacles are detected
- Emergency SOS button for immediate assistance
- Telegram notification system for multiple users
- WiFi-enabled remote communication
- Automatic online status notification when the device starts

## System Components
- ESP32 Microcontroller
- HC-SR04 Ultrasonic Sensor
- Servo Motor
- Buzzer
- Push Button (SOS)
- WiFi Network
- Telegram Bot

## Project Outcome
The Smart Blind Stick enhances mobility and safety for visually impaired users by providing obstacle detection and emergency communication capabilities. The integration of Telegram alerts enables caregivers and family members to receive immediate notifications during emergencies.
